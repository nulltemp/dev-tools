# 未対応の改善点

プロジェクト全体を見直した際に見つかった、まだ対応していない改善点の一覧です。対応したものはこの一覧から削除してください。

## コード品質・保守性

### MUI を設定しているが使っていない

`@mui/material` と `@emotion/*` を導入し、`layout.tsx` で `ThemeProvider` と `AppRouterCacheProvider` を設定しているが、MUI のコンポーネントはどのページでも使われていない。ダークモードの設定も `globals.css` の CSS 変数と `theme.ts` の `colorSchemes` で二重になっている。

- 対応案: MUI を使っていく方針ならツールページを MUI コンポーネントに置き換える。使わないなら依存とプロバイダーを外してバンドルを軽くする。

### 用途に合わない CSS クラスを流用している

`jwt-decoder/page.tsx` の有効期限の表示と「署名の検証は行っていません」の注記に `.char-count`（文字数表示用のクラス）を使っている。また、期限切れでも見た目が変わらない。

- 対応案: `.note` や `.warning-message` のような汎用クラスを `globals.css` に追加する。期限切れのときは `--warning` / `--error` の色で表示する。

### ページの書き方がそろっていない

- `char-count/page.tsx` は `export default function`、`json-formatter` と `jwt-decoder` は `React.FC` で書かれている。
- `theme.ts` だけシングルクォートを使っている。
- Prettier などのフォーマッターが入っていない。

## UX・アクセシビリティ

### 見出しの順番

DOM の並びで、サイドバーの `<h2 className="sidebar-title">ツール</h2>` が各ページの `<h1>` より前に来る。

### JSON整形のエラーで場所がわからない

`formatJson.ts` はエラーメッセージを「無効なJSONです」に固定しているため、どこが間違っているか分からない。

- 対応案: `JSON.parse` が投げるエラーのメッセージ（何文字目か）を表示する。

### JWTデコーダーの入力まわり

- `Bearer xxx` の形で貼り付けると形式エラーになる（先頭の `Bearer ` を取り除くとよい）。
- `iat` / `nbf` は日時として表示されない。
- 5部構成のトークン（JWE）にも「3部構成である必要があります」とだけ表示される。

### 細かい CSS の調整

- `.card:hover` のアニメーションが `prefers-reduced-motion`（動きを減らす設定）を考慮していない。
- `.card:hover` の影の色がハードコードされていて、ダークモード用の変数（`--card-shadow` など）を使っていない。

### 404ページが英語のまま

`out/404.html` のタイトルと本文が Next.js 既定の「This page could not be found」になっている。

- 対応案: `src/app/not-found.tsx` を追加し、日本語の案内とホームへのリンクを置く。

### JSON整形の表示幅が狭い

`.input-section` の `max-width` が 600px のため、広い画面でも深いネストの JSON が折り返される。

- 対応案: 整形結果の表示だけでも幅を広げる。

## バグ

### JWTの有効期限の判定と表示

`decodeJwt.ts` の `exp` の扱いに2つ問題がある。

- RFC 7519 では `exp` の時刻ちょうども期限切れだが、`<` で比較しているため有効と判定される（`<=` にする）。
- `exp` が極端に大きい（例: `1e20`）と日付が不正になり、`Invalid Date` と表示される。

## セキュリティ・信頼性

### 入力が送信されないことを明記していない

JWT は認証情報そのものだが、入力の扱いがページに書かれていない。入力値を送信するコードは現状ないものの、このページでも Google Analytics は動いている。

- 対応案: 「入力はブラウザ内で処理され、送信されません」と表示する。CSP で接続先を制限して、説明の裏付けにする。

## 機能追加

- 文字数カウンター: 空白・改行を除いた文字数、行数、バイト数を追加する。
- JSON整形: インデント幅の選択、圧縮、Ctrl+Enter での実行を追加する。
- 新しいツール: Base64、URLエンコード、UUID生成、Unixタイムスタンプ変換など。

## SEO

各ツールページの内容が説明1文と入力欄だけになっている。

- 対応案: 使い方や用語の短い解説を追加する。

## テスト・運用

### UIのテストがない

テストは純粋なロジックのみ（Vitest の node 環境）で、ページの操作を確認するテストがない。

- 対応案: 主要な操作を確認する E2E テストを数本追加する。

### 依存関係の管理

- Dependabot などの自動更新が設定されていない。
- `.nvmrc` や `engines` による Node バージョンの固定がない（CI は Node 22）。
- MUI（7→9）、TypeScript（5→7）、ESLint（9→10）はメジャーバージョンが遅れている（2026-10-30 時点）。MUI は使うかどうかを決めてから対応する。
