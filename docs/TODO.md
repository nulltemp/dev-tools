# 未対応の改善点

プロジェクト全体を見直した際に見つかった、まだ対応していない改善点の一覧です。対応したものはこの一覧から削除してください。

## コード品質・保守性

### フォーマッターがない

- Prettier などのフォーマッターが入っていない。

## セキュリティ・信頼性

### 入力が送信されないことを CSP で裏付けていない

JWTデコーダーには「入力はブラウザ内で処理され、送信されません」と表示しているが、CSP で接続先を制限していないため、表示の裏付けがない（Google Analytics は動いている）。

- 対応案: CSP で接続先を GA などに限定する。静的エクスポートなので、ホスティング側のヘッダーか `<meta>` で設定する。

## 機能追加

- 文字数カウンター: 空白・改行を除いた文字数、行数、バイト数を追加する。
- JSON整形: インデント幅の選択、圧縮、Ctrl+Enter での実行を追加する。

## テスト・運用
